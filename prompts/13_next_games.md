## Visao Geral

Para o caso de proximos jogos o usuario podera ver os jogos todos os jogos que irao acontecer independente da regiao desde que informe para o usuario de qual regiao seria o jogo que ira acontecer. Tambem preciso que jogos futuros mesmo que futuro de um mês apareça para o usuario

## Task

- O usuario podera ver todos os jogos de todas as regioes
- Deve conter a informacao para o usuario de data, hora e qual regiao pertence o jogo
- Jogos muito futuros exemplo champios que acontece no final do mes de Setembro deve aparecer
