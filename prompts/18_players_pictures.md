## Visao Geral

Assim como o vlr.gg que é de onde o scrap acontece tem a imagens dos players aparecendo para cada um, as mesmas imagens utilizadas devem aparecer para o players no website. No scrap as imagens dos players tambem sao relevantes para ser colocadas no mercardo nos cards dos players e tambem na escalacao do usuario quando o time esta montado e o resumo.
Toda informacao que contenha o player ou seja exposto o nome do player ou algo do tipo, tudo deve trazer a imagem dele como base de conhecimento para o usuario

## Task

- No mercado nos cards dos players deve se ter a imagem/foto do player assim como o site que faz scrap
- Na escalacao onde tem o time montado tambem deve aparecer a imagem do player para referencia para o usuario
- No resumo o mesmo para as imagens dos players
- O mesmo vale para melhor pontuador e pior onde a imagem do player deve aparecer
- Na aba de inicio no grafico dos que aparece para o usuario refetente ao player tambem deve ter a imagem do player
