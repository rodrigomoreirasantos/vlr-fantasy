## Visao Geral

- O filtro para classes dos player no Mercado (ex. Duelista, Iniciador, Controlador) devem ser apresentados por abas
- O usuario deve selecionar as classes por abas e ao selecionar a aba aparecem ao todo os jogadores mais baratos para os mais caros e depois os que ele nao pode comprar
- A venda do player deve ser mais evidente para o usuario pois nao esta trazendo uma experiencia boa para o usuario que pode nao ver a opcao de vender jogador
- Para os resumos dos cards de jogadores para contratar nao se deve colocar o valor do saldo que vou ficar, apenas o valor do player que o usuario ira pagar
- Remover tambem a ultima pontuacao do jogador, deve ser mostrado o valor do player na atualidade
