## Agent

- Crie um agente que seja responsavel por criar planos de trabalho
- O plano deve sempre utilizar a skill .claude\skills\grill-me para criação dos planos
- Após o plano criado o mesmo **SEMPRE** deve ser salvo .claude\plans
- **NUNCA** execute o plano assim que pronto pois o agente sera responsavel apenas por criar planos
- **SEMPRE** deve utilizar o plan mode para criar o plano
- Apos o plano criado me informe que o plano foi criado
- **SEMPRE** após o plano criado me explique o plano como para uma criança de 5 anos, utilize o ELI5 para a explicacao
