## Visao Geral

O scrap das paginas realizados pelo plano .claude\plans\08-pipeline-vlr-scraping.md devem ser automatizados para que eu nao precise rodar um comando para realizar o scrap. Ele deve ser feito totalmente de forma automatica e sempre utilizando a informacao mais atual. O scrap deve acontecer sempre que uma alteracao acontecer nos sites em que o scrap acontece. Exemplo se algo mudar nesses sites sendo elas relacionado a troca de jogador de time, seja em jogos, seja em stats de players ou seja em times tudo deve ser atualizado da maneira que o scrap vem das paginas

# Task

- O scrap deve acontecer assim que algo for mudado no website onde o scrap acontece
- O scrap deve ser **SEMPRE** o mais atual
- Todas as informacoes vinda do scrap devem ser seguidas em meu website, caso algo mude no scrap feito meu website deve seguir o mesmo
- O sistema todo sendo ele JOGOS, TIME, REGIAO, PLAYERS e outros **SEMPRE** devem seguir as informacoes mais atual do scrap
- O trigger para o scrap acontecer deve depender de qualquer mudanca no website onde o scrap acontece
- **NUNCA** devo rodar um comando para que o scrap aconteça ele deve ser feito totalmente de maneira automatica
