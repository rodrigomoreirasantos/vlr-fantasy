## Visao Geral

Usuarios de timezone diferente do meu irao acessar a plataforma o que causa um certo probelma com o caso dos horarios de jogos do scrap onde eles foram baseados em meu fuso horario. No caso uma pessoa que acessa o website do Brasil por exemplo para os horarios dos jogos ira imapctar diretamente pois estamos em fuso horario diferente, pois o website trouxe os jogos com base no timezone de Motreal

## Task

- O usuario deve ser capaz de verificar os jogos e o horario que o mercado fecha com base em seu timezone
- Nao usario o meu timezone como os horarios dos jogos pois isso vai depender do timezone do usuario
- Voce pode utilizar o scrap como base de dados de informacao porem o calculo de timezone deve ser feito com base no timezone do usuario
